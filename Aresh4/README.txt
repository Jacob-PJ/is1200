A project for the course IS1200 at KTH. The code builds a Tetris game that runs on a UNO PIC32 microcontroller.
The game is developed in C and is built on MIPS.



To compile and run the code, you'll need to use the
MSYS MINGW64 or MSYS UCRT64 software development environments.
Navigate to the project directory using commands in MINGW. 
Once inside the Aresh4 directory, execute the command "make"" to compile the code. If the compilation 
completes without errors, you can then run the command "make install" to upload the code to the ChipKit.
